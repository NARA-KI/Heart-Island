## 一、修改目标

Beta 0.9.8.1 结果页被反馈"信息过碎、模块太多、标题太散"。用户最想看的是自己性格中最主要最共鸣的东西，而不是分散的小卡片。

本次做减法重构：合并模块、减少卡片、弱化AI报告感，改为一条连续有共鸣的阅读路径。

## 三、模块合并详情

### 3.1 "最像你的三个瞬间" → 删除为独立标题

原 3 张 01/02/03 证据卡片替换为一段 120-160 字的流动文本。12 种核心人格各有一份手工撰写的"心理活动"式描述，不需要标题数字和卡片边框。

示例（守门人型）：
> "你很少主动说'我喜欢你'，但会记住对方三个月前随口提过的书，然后悄悄放在Ta桌上。别人问你怎么不说话——其实你心里已经说了很多，只是还没准备好让它们出来。"

### 3.2 "你真正想要的爱" → 合并进入说明书

原独立的"暖信"风格卡片替换为一段 100-140 字的柔和解释。不再单独做大卡片。12 种核心人格各有手工撰写版本。

示例（守门人型）：
> "你并不需要一个破门而入的人。你需要的，是那个在门口坐着等你、等你亲手把钥匙递给他的人。"

### 3.3 "为什么是这个主岛" → 压缩为 2-3 句

原占据大量屏幕的维度条列表（全部6个关键维度 + 排除项）改为最多 3 个自然句子：
- 最高分维度：说明你的高分如何呼应主岛特质
- 中间取舍维度：解释为什么你不是别的类型
- 最低分维度：说明排除了哪些类型

不再显示维度条（footprint bars），不再列出全部排除项。

### 3.4 关系画像 → "你在亲密关系里的惯性"

原 4-5 个独立模块（关系回声、关系优势、暗礁提醒、别人误解你、适合关系节奏）合并为 3 个小块：
1. 关系优势
2. 容易卡住的地方（合并盲区 + 误解）
3. 适合你的关系节奏

关系回声规则保持不变但视觉弱化：
- gap ≤ 5：模块开头一段浅色斜体提示
- 5 < gap ≤ 12：模块底部小字"关系回声：XX型"
- gap > 12：不显示

### 3.5 成长建议 → "给你的关系建议"

原多卡（短期/关系/长期 + 不适合消耗）压缩为 3 条场景建议：
1. 靠近时
2. 不安时
3. 冲突时

每条控制在 60-90 字，语气像真实建议而非心理学条目。映射逻辑：growthPlan.shortTerm → 靠近时, .relationship → 不安时, .longTerm → 冲突时。如 growthPlan 为空则从 dynamicAdvice/growthTips/avoidPattern fallback。
