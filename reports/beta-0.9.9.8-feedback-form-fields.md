# 心岛计划 Beta 0.9.9.8 反馈收集字段方案

## 1. 设计原则

反馈字段不要太多，优先收集能帮助判断“能不能公开测试”的信息：

- 能不能打开；
- 能不能做完；
- 结果准不准；
- 分享卡能不能保存；
- 哪些地方卡住或看不清。

不收集过度隐私信息，不要求手机号、微信号、真实姓名。

## 2. 必填字段

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| 设备和浏览器 | 单选 / 短填 | 判断 iPhone / 安卓 / 微信 / Safari / Chrome 差异 |
| 是否能打开页面 | 单选：能 / 不能 / 需要点继续访问 | 判断域名访问问题 |
| 是否出现微信访问提示 | 单选：出现 / 没出现 / 不在微信打开 | 判断微信提示影响 |
| 是否完整做完 36 题 | 单选：是 / 否 | 判断主流程是否阻断 |
| 结果人格名称 | 短填 | 对照反馈和结果类型 |
| 结果准确度 | 1-5 分 | 判断结果价值 |
| 是否愿意保存分享卡 | 单选：愿意 / 不愿意 / 一般 | 判断传播意愿 |
| 分享卡是否能保存 | 单选：能 / 不能 / 没试 | 判断分享链路 |
| 页面哪里卡住或看不清 | 长填，可填“无” | 收集关键 bug |

## 3. 可选字段

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| 哪一句最像你 | 长填 | 判断命中句和结果页价值 |
| 哪里不像你 | 长填 | 判断文案和评分问题 |
| 分享卡保存方式 | 单选：按钮 / 长按 / 系统分享 / 不能保存 | 判断浏览器差异 |
| 是否愿意转发给朋友 | 单选：愿意 / 不愿意 / 看情况 | 判断传播潜力 |
| 其他建议 | 长填 | 收集开放反馈 |

## 4. 不建议收集的字段

| 字段 | 原因 |
| --- | --- |
| 手机号 | 没必要，增加隐私压力 |
| 微信号 | 没必要，降低填写意愿 |
| 真实姓名 | 没必要 |
| 年龄精确值 | 当前阶段不需要 |
| 详细感情经历 | 过度隐私 |
| 定位 / 城市 | 当前阶段不需要 |
| 截图强制上传 | 会增加反馈成本，可选即可 |

## 5. 推荐表单结构

### 第一段：设备和打开情况

1. 你用的设备和浏览器是？
2. 页面能打开吗？
3. 有没有出现“非微信官方网页”的提示？

### 第二段：测试流程

4. 你有没有完整做完 36 题？
5. 做题时有没有卡住、看不清或点不到？

### 第三段：结果反馈

6. 你的结果人格是什么？
7. 你觉得结果准确度几分？1-5 分
8. 哪句话最像你？
9. 哪里不像你？

### 第四段：分享卡

10. 你愿意保存或分享这张卡吗？
11. 分享卡能生成吗？
12. 分享卡能保存吗？

### 第五段：其他建议

13. 还有什么想吐槽或建议？

## 6. 最小可用表单版本

如果只想发一个很短的反馈表，建议只保留：

1. 设备和浏览器；
2. 是否能打开；
3. 是否完整做完；
4. 结果人格；
5. 准确度 1-5 分；
6. 分享卡能不能保存；
7. 哪里卡住或看不清；
8. 其他建议。
