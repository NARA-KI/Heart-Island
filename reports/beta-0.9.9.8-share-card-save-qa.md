## 3. 建议检查 canvas / 图片尺寸

在浏览器开发环境或调试脚本中检查：

- 分享卡预览 `img.src` 是否为 `data:image/`；
- data URL 对应图片像素宽高；
- canvas 生成尺寸是否满足手机分享需求；
- 页面内预览是否只是 CSS 缩放；
- 保存后的实际图片尺寸是否低于预期。

| 保存后图片高度 | 待测 |
| 文件大小 | 待测 |

## 6. 如果发现问题，优先级判断

| 问题 | 优先级 | 建议 |
| --- | --- | --- |
| 分享卡无法生成 | P0 | 立即修 |
| 保存按钮完全无效 | P0 / P1 | 先判断是否浏览器限制，再补提示 |
| 微信不能保存但 Safari 可保存 | P1 | 增加“请用系统浏览器打开”提示 |
| 保存后图片模糊 | P1 | 检查 canvas 输出尺寸 |
| 保存后图片偏暗 | P2 | 先确认不是页面预览缩放，再考虑轻调 |
| 页面内预览偏小但保存图正常 | P3 | 可暂不处理 |

## 7. 当前建议

- 暂不重做分享卡模板。
- 先补齐真实设备保存图。
- 如果只是页面内预览偏小，不应急着改视觉。
- 如果微信内保存失败，优先补轻提示，而不是重做功能。
