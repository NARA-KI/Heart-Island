## 3. 每题修改前后对照

### q30 — NV（正向，快速版）

**修改理由**：消除 B 选项对 SC（安全感）的跨构念污染。原 B "关系太不确定，随时可能变化" 测量的是对不确定性的恐惧，不属于 NV。

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 题干 | 长期关系里，你最怕哪一种状态？ | 一段关系稳定了很久。你内心更接近哪种感受？ |
| A (100) | 一切太重复，像再也没有新风景。 | 我开始觉得闷，总想一起找些新的东西。 |
| B (0) | 关系太不确定，随时可能变化。 | 我不太需要变化，安安静静就挺好。 |
| C (67) | 只有稳定，没有一起探索的空间。 | 我希望能不时一起尝试没做过的事。 |
| D (33) | 每天都很好预测，很少出现意外惊喜。 | 稳定就好，偶尔有点变化是加分。 |

### q53 — RI（正向，快速版）

**修改理由**：修复题干与选项层面不匹配（原题问问"怎样理解"，选项答"怎么做"）。B 从"判断值不值得"改为直接描述减少投入。D 去掉互惠条件（CM 污染）。去掉金融术语"加码""止损"。

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 题干 | 当一段重要关系进入困难期，你通常怎样理解"继续投入"？ | 一段重要的关系进入了困难期。你心里更接近哪种想法？ |
| A (100) | 如果还重要，我愿意继续把心力放进去。 | 只要这段关系还重要，我就愿意继续付出。 |
| B (33) | 我会看这段关系是否还值得继续加码。 | 我会先收回来一点，少放些心思在关系上。 |
| C (0) | 我更倾向及时止损，不让自己陷太深。 | 我觉得该停下来了，不想越陷越深。 |
| D (67) | 我愿意留下，但需要看到双方都在努力。 | 我愿意再等一段时间，看能不能好转。 |

### q55 — RI（正向，非快速版）

**修改理由**：保留原始"投入成本影响"子维度（架构文档 line 168 明确标注），去掉 AI 翻译腔和"被经营"被动语态。

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 题干 | 你们已经一起投入了很多时间和心力，但眼前关系进入低谷。过去的投入会怎样影响你的选择？ | 你们已经为这段关系付出了很多，但现在关系不如以前了。你更接近哪种？ |
| A (100) | 它会让我更想再努力一次。 | 付出这么多，我还是想再努力一次。 |
| B (33) | 我会承认投入过，但不一定继续留下。 | 付出了很多，但我也可以选择停下来。 |
| C (67) | 我会看这段关系是否还能继续被经营。 | 过去的付出让我想多留一阵，但我也在看现在合不合适。 |
| D (0) | 我不想因为已经投入而拖住现在。 | 不能因为已经付出很多，就继续勉强自己。 |

### q56 — MN（正向，快速版）

**修改理由**：去除过度文艺表达（"被海风磨平的名字""爱存在过的证据""推动我继续理解这段关系的线索"）。统一为"回忆对当下的心理占据程度"单一判断标准。

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 题干 | 在心岛旧码头，你看见许多被海风磨平的名字。对你来说，关系里的共同记忆更像什么？ | 一段关系结束后，那些共同回忆在你心里占多大的分量？ |
| A (100) | 是爱存在过的证据，我会很珍惜。 | 占很大的分量，它们一直在我心里。 |
| B (33) | 是一部分经历，但不该决定现在。 | 有一点分量，但不会太重。 |
| C (67) | 是推动我继续理解这段关系的线索。 | 有分量，想起来的时候会想一阵。 |
| D (0) | 是过去的事，我不太会反复翻看。 | 没什么分量了，我已经向前走了。 |

### q57 — RI（正向，快速版）

**修改理由**：去掉社会赞许性高的"不勉强自己"表达和互惠条件"双方都在投入"（CM 污染）。去掉"评估""前提"等书面/管理用语。场景聚焦"累了但还在关系中"的压力取舍（架构 line 170）。

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 题干 | 关系变得很重，需要持续投入时间和心力。你更接近哪种选择？ | 这段关系让你觉得越来越累。你更接近哪种？ |
| A (100) | 如果这段关系重要，我会继续把心力放进去。 | 虽然累，我还是想继续。 |
| B (33) | 我会先评估自己还能投入多少。 | 我会慢慢淡出，不再那么用心。 |
| C (0) | 我会开始减少投入，避免继续变重。 | 太累了，我会退出来。 |
| D (67) | 我愿意继续，但前提是双方都在投入。 | 我会减少投入，但还不会离开。 |
