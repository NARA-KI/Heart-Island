# 心岛计划 Beta 0.9.9.6 UI 简化改造报告

## 1. 总结结论

本轮完成 Beta 0.9.9.6 UI 简化改造，范围控制在首页、做题页、结果页 Hero / 分享入口和验证脚本。

- 首页从“多信息展示”收敛为标题、核心说明、补充信息、主 CTA 优先，卖点卡、图鉴入口、免责声明进一步弱化。
- 做题页将场景图从 28vh 主视觉压缩为顶部氛围条，题目和选项成为首屏主体。
- 结果页 Hero 收敛为更紧凑的身份卡结构，`生成分享卡` 从弱提示升级为首屏明确行动。
- 分享卡链路已通过脚本验证：Hero 分享入口可点击，能生成 data image 预览。
- 版本已统一为 `Beta 0.9.9.6` / `0.9.9.6-beta`，并同步到 `deploy` 镜像。
- 本轮没有修改题库、人格文案、评分算法、评分参数、人格 targetVector。

## 4. 首页 UI 简化说明

首页移动端首屏继续保留：

- `心岛计划` 标题；
- 一句核心说明；
- `36 道题 · 约 5 分钟 · 生成你的心岛人格卡`；
- `开启心岛航行` 主按钮；

- 卖点卡改为低透明、低权重、下移，不再与主按钮抢视觉。

## 5. 做题页 UI 简化说明

本轮没有删除或替换场景图，而是降低其首屏权重：

- 移动端场景区从 28vh 压缩为顶部氛围条，约 88-118px。
- 场景图透明度降低，保留地点氛围但不再压过题目。
- 题卡上移，题目和选项成为页面主体。
- 章节提示浮层缩小并移到氛围条区域，避免遮挡题目。
- 选项按钮最小高度为 54px，不小于 44px。
- `上一题` 功能通过脚本验证：答完第一题后按钮可见并可点击返回。

390px 验证结果：

- 无横向溢出；
- 题目区域位于首屏更靠前；
- 首屏可见 4 个选项；
- 选项按钮最小高度 54px；
- 场景仍有深海航行氛围，但不再占据主体阅读区。

## 6. 结果页 Hero 与分享入口简化说明

结果页 Hero 本轮保持现有 DOM 和结果内容，仅通过样式收敛层级：

- Hero 变为更紧凑的身份卡；
- 人格名、匹配度、3 个关键词、命中句在首屏可见；
- 拟人图缩小为首屏可见的主要视觉；
- 置信说明在移动端隐藏，降低首屏信息密度；
- `生成分享卡` 按钮升级为明确的主行动样式，不再只是低透明文字入口；
- 详细报告、Top5、旅途回顾、图鉴、反馈仍在下方保留。

390px 验证结果：

- 人格名可见；
- 3 个关键词可见；
- 命中句可见；
- 拟人图可见；
- `生成分享卡` 入口可见；
- 无横向溢出。
