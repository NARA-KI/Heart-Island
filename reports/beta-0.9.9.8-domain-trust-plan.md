# 心岛计划 Beta 0.9.9.8 域名与微信访问提示处理方案

## 1. 当前临时域名风险说明

真实手机视频中，使用腾讯云临时域名访问时，微信 / 内置浏览器出现提示：

`非微信官方网页，请确认是否继续访问。`

这不是普通前端 bug，也不是通过改 `index.html` / `app.js` / `styles.css` 就能直接消除的问题。它属于外部浏览器、域名信任、访问来源和平台安全策略共同造成的访问提示。

当前风险：

- 用户首次打开会被中断；
- 普通用户可能不知道是否应继续；
- 小范围熟人测试可以接受；
- 公开传播、朋友圈、小红书跳转前不建议忽略；
- 如果测试者以为页面“不安全”，会影响转化和反馈质量。

## 2. 对用户转化的影响

| 场景 | 影响 |
| --- | --- |
| 熟人测试 | 可提前说明，影响可控 |
| 社群测试 | 会增加解释成本，部分用户可能退出 |
| 朋友圈传播 | 风险较高，很多用户不会继续访问 |
| 小红书 / 外链传播 | 可能降低点击完成率 |
| 正式作品集展示 | 不适合作为最终公开入口 |

## 3. 短期可接受方案

短期小范围测试可以继续使用当前腾讯云临时域名，但需要明确提示用户：

- 如果微信提示“非微信官方网页”，点击“继续访问”即可；
- 如果打不开，可以复制链接到 Safari / Chrome；
- 当前是测试版，不需要输入手机号、登录或付款；
- 结果仅用于自我探索，不是专业心理诊断。

短期不建议：

- 在朋友圈大规模扩散；
- 在小红书正文中强依赖微信内置浏览器打开；
- 把临时腾讯云域名作为最终作品集链接。

## 4. 中期正式域名方案

公开测试前建议准备正式访问入口：

1. 购买或使用已有正式域名。
2. 绑定到腾讯云 CloudBase / Web 应用。
3. 配置 HTTPS。
4. 如果面向国内公开访问，确认是否需要备案。
5. 用微信内置浏览器重新测试是否仍提示。
6. 如果仍提示，评估是否需要公众号、小程序、可信落地页或更稳定的承接页面。

## 5. 腾讯云自定义域名检查项

需要在腾讯云侧确认：

- 当前 CloudBase / Web 应用是否支持自定义域名；
- 自定义域名绑定步骤；
- 是否要求 CNAME 解析；
- 是否支持自动 HTTPS 证书；
- 证书签发和续期方式；
- 是否需要把静态资源路径一并纳入同域；
- 部署后是否会影响 `assets/` 相对路径加载；
- 是否有缓存策略，需要清理 CDN / 静态托管缓存。

## 6. HTTPS 检查项

上线前检查：

- 访问入口必须是 `https://`；
- 证书有效且未过期；
- 页面内所有资源也通过 HTTPS 加载；
- 没有 mixed content；
- iPhone Safari / 安卓 Chrome 不提示证书风险；
- 微信内置浏览器能正常打开。

## 7. 备案检查项

如果使用国内服务器 / 国内云服务面向公开访问，需要确认：

- 域名是否已备案；
- 腾讯云产品是否要求接入备案；
- 备案主体是否与域名主体一致；
- 若未备案，是否只能先用于小范围测试；
- 是否需要先用临时域名或海外节点过渡。

具体备案规则以腾讯云和当地监管要求为准，本报告不作为法律意见。

## 8. 微信环境仍可能提示的风险

即使绑定正式域名并配置 HTTPS，微信环境仍可能因为以下原因提示或限制：

- 域名较新，信任度不足；
- 分享来源异常；
- 页面内容被平台策略误判；
- 外链打开策略变化；
- 用户所在微信版本差异；
- 域名未接入公众号 / 小程序可信场景。

因此，正式域名不是绝对保证，需要真机复测。

## 9. 小范围测试用户提示文案

可直接发给测试用户：

> 这是一个恋爱人格测试，大约 5 分钟。  
> 如果在微信里打开时出现“非微信官方网页”的提示，可以点“继续访问”。  
> 如果打不开，可以复制链接到 Safari / Chrome 打开。  
> 做完后会生成你的心岛人格结果，也可以试试分享卡能不能保存。  
> 这不是专业心理诊断，只是一个测试版体验，欢迎告诉我结果准不准、哪里卡住。

## 10. 公开测试前推荐路径

推荐顺序：

1. 当前临时域名继续用于熟人小范围测试。
2. 收集结果准确度、分享卡保存、微信打开问题。
3. 准备正式自定义域名。
4. 配置 HTTPS。
5. 确认备案或部署合规路径。
6. 用 iPhone 微信、安卓微信、Safari、Chrome 做完整复测。
7. 若微信仍提示，准备“复制到浏览器打开”的备用说明。
8. 再进入朋友圈 / 小红书 / 社群公开传播。

## 11. 当前建议结论

- 不建议通过前端代码尝试“消除”微信提示。
- 小范围测试可以继续。
- 公开测试前应优先解决正式域名、HTTPS、备案和微信环境复测。
- 这件事优先级高于继续微调首页、做题页或结果页 UI。
