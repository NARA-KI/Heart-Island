# 心岛 v2.0 题库典型人格模拟作答执行报告

## 1. 本轮结论摘要

本轮版本目标：`v2.0-question-bank-persona-simulation-execution`。

本轮只做模拟作答执行，不改代码，不接入正式题库，不修改评分机制，不修改人格体系，不修改核心结果算法。

本轮采用人工模拟方式：按 15 构念高/中/低分路径，推演 15 个主性人格和 6 组易混人格在 60 题候选题中的作答倾向，并判断预期 Top1、Top2 和误判风险。

核心结论：

| 项目 | 结论 |
| --- | --- |
| 主性人格理想路径 | 人工预期 15/15 可命中，但 5 个为低置信命中。 |
| 易混人格对照 | 6/6 可解释性拉开，但 3 组仍需重点观察。 |
| 风险题压力 | 未完全通过；q06、q15、q21、q47 仍建议人工拍板或继续观察。 |
| 是否建议回到题目小修 | 局部建议，不建议大规模重写。 |
| 是否建议进入结构化题库草案 | 不建议。 |
| 是否建议进入代码实现 | 不建议。 |

## 3. 模拟方法说明

本轮不调用正式代码，不运行 `app.js`、`core/scoring.mjs` 或任何正式评分脚本。

本轮人工模拟规则：

1. 按每个人格的核心构念、辅助构念、排斥构念设计作答。
2. 核心构念倾向选择 100 分或 67 分选项。
3. 辅助构念倾向选择 67 分或 33 分选项。
4. 排斥构念倾向选择 0 分或 33 分选项。
5. 每组记录 A/B/C/D 选项序列摘要、关键题选择、预期 Top1、可能 Top2/Top3。
6. 本轮只做人工模拟验证，不代表正式算法跑分结果。
