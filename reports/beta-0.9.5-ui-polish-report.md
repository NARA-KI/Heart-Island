## 一、整体视觉方向 ✅

从 "AI生成感 / 深色玻璃网页" 转型为 "深海航行 + 手账海图 + 心岛人格卡片"。

### 新色彩系统
| 色彩 | 旧值 | 新值 | 用途 |
|------|------|------|------|
| 深海底色 | `#060d1f` | `#0a1628` | 更温暖的深海基调 |
| 暖沙金 | `#c9a75b` (gold) | `var(--sand-gold)` | 主色调，温暖自然 |
| 潮汐青 | `#5abcb9` (teal) | `#4a9e9b` (tidal-cyan) | 降低饱和度 |
| 珊瑚 | `#c9707c` (rose) | 不变 | 点缀色 |
| 迷雾紫 | `#3d3560` (mist-purple) | `#5e5688` | 降低饱和度，退出主角色 |

### 变量别名策略
所有旧变量名 (`--gold`, `--teal`, `--rose`, `--glass-bg`, `--glass-border`, `--glass-blur`) 通过别名指向新值，确保 **所有现有 CSS 选择器无需修改即可生效**。

### 关键参数变化
- `--glass-blur`: `blur(20px)` → `blur(8px)` （大幅降低AI玻璃感）
- `--glass-bg`: `rgba(10,18,38,0.65)` → `rgba(18,30,52,0.72)` （更温暖的卡片底色）
- `--white-dim`: `0.6` → `0.55` （文字柔和化）
- `--white-faint`: `0.3` → `0.28` （弱化次要文字）

## 三、做题页优化 ✅
