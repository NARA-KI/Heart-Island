## 2. scene-27 A/C 分数互换前后说明

### 互换前（有问题）

| 选项 | score | 语义判断 |
|------|:-----:|------|
| A: 检查行囊，把属于别人的东西还给别人，属于自己的留着 | **100** | 这更像成熟边界（moderate CA），不是最高照顾承担 |
| C: 觉得每样东西都很重要，舍不得放下任何一件 | **33** | 这更像高照顾承担/过度承担（high CA） |

**问题**：选"舍不得放下"的用户只得 33 分，CA 被严重低估。

### 互换后（已修复）

| 选项 | score | memoryTag |
|------|:-----:|------|
| A: 检查行囊，把属于别人的东西还给别人，属于自己的留着 | **33** | 能分清哪些责任属于自己 |
| C: 觉得每样东西都很重要，舍不得放下任何一件 | **100** | 总觉得每一份重量都不该被放下 |

**B/D 不变**：B=67 "学会选择性地承担"，D=0 "轻松前行比背负更重要"。

## 3. 6 个文案微调前后对照

### 3.1 scene-16「顺风的方向」IN 维度 D 选项

| | 文案 |
|------|------|
| **修改前** | 逆着风走——你想看看不服从风向会怎样 |
| **修改后** | 停在原地，等风自己过去——你不想被任何方向催着走 |
| **原因** | 原文"逆着风走"是反叛式主动行为，与 score=0（低主动推进）矛盾 |

### 3.2 scene-17「远方的篝火」IN 维度 D 选项

| | 文案 |
|------|------|
| **修改前** | 如果你真的需要火，你可以自己生一堆 |
| **修改后** | 不再追那团火，原地坐下等夜色过去 |
| **原因** | 原文"自己生火"隐含主动创造能力，与 score=0（低主动推进）矛盾 |

### 3.3 scene-22「古老的钟」ST 维度 D 选项

| | 文案 |
|------|------|
| **修改前** | 不去碰它——承诺不是靠一口钟来定义的 |
| **修改后** | 不去碰它——你不想让任何承诺提前固定未来 |
| **原因** | 原文读起来像是对承诺有自己的高标准，反而是高 ST；修改后明确表达"不想被固定" |

### 3.4 scene-04「独行小径」AU 维度 D 选项

| | 文案 |
|------|------|
| **修改前** | 不走这条路，另找一条更宽阔的 |
| **修改后** | 退回山脚，想等有人一起再走这条路 |
| **原因** | 原文"另找一条"可解读为换个方式独行；修改后明确表达需要陪伴 |

### 3.5 scene-05「盘旋的鹰」AU 维度 D 选项

| | 文案 |
|------|------|
| **修改前** | 低下头继续走，不被一只鹰牵动思绪 |
| **修改后** | 觉得鹰飞得太远太孤单，还是更想回到有人陪伴的路上 |
| **原因** | 原文"不被牵动思绪"更接近低 EV（情绪不敏感），而非低 AU；修改后明确指向对陪伴的偏好 |

### 3.6 scene-34「月下的湖水」EV 维度 C 选项

| | 文案 |
|------|------|
| **修改前** | 觉得湖水的涨落让人有些不安——太过安静了 |
| **修改后** | 看了一会儿，没太多感觉，只觉得这里比想象中安静 |
| **原因** | 原文"让人不安"说明情绪被环境影响（中等 EV），与 score=33 的"低情绪敏感"定位矛盾 |

## 9. 是否建议进入 20-30 人小范围测试

### ✅ 建议现在开放 20-30 人小范围测试

**理由：**

1. ✅ 所有高风险选项已归零（5 → 0）
2. ✅ 所有中风险选项已归零（6 → 0）
3. ✅ 144 个选项语义与 score 100% 对齐
4. ✅ 12/12 维度路径测试通过（CA 高路径警告属预期行为，见下方说明）
5. ✅ 20/20 反向语义测试通过
6. ✅ 20/20 自匹配通过
7. ✅ 无类型消失（最低 1.1%）
8. ✅ 无超高频类型（最高 10.6%，<15%）
9. ✅ app.js / core/scoring.mjs / scripts/option-alignment-audit.mjs 三文件题库完全同步

**CA 维度路径说明：**
修复后 CA 高路径（选全 A）得分为 78（<85），这是因为 scene-27 A 从 100 降为 33。这不是 bug，而是正确行为——"区分责任还回别人的东西"确实是中等照顾承担（33），真正的高 CA 路径应该是 scene-25 A + scene-26 A + scene-27 C（过度承担=100）。审计脚本用固定选项 ID 路径（全 A）测试，无法自动适应语义变化，属于测试脚本限制。

**测试期间重点观察：**
- 用户是否觉得主副岛差距足够清晰（gap≤5=70.5%）
- 极光型（1.1%）、星火型（1.8%）、黑森林型（1.7%）在真实用户中是否合理出现
- 深海型（8.8%）是否在真实用户反馈中准确
