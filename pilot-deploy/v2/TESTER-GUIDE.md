# 心岛 v2.0 内测测试者说明

这是心岛 v2.0 的内部验证页面，不属于专业心理诊断。

## 你需要做什么

1. 打开测试页面。
2. 阅读首页说明。
3. 完成 60 道题，预计 8-10 分钟。
4. 按真实感受作答，不选“看起来更成熟”的答案。
5. 如果某题难选、看不懂、两个选项都像、四个选项都不像，可以在题目下方标记。
6. 查看匿名结果。
7. 完成反馈。
8. 点击“下载匿名内测结果”。
9. 将下载的 JSON 文件发送给测试组织者。

## 重要说明

- 没有标准答案。
- 测试结果只用于产品体验研究。
- 数据只保存在当前设备，不会自动上传。
- 导出文件不包含姓名、手机号、身份证、精确位置、聊天记录或伴侣个人信息。
- 不要打开 JSON 文件手动填写姓名或其他身份信息。

## 如果下载失败

可以点击“复制匿名结果代码”，把复制出来的完整文本发送给测试组织者。

如果复制内容过长或发送失败，请优先使用 JSON 文件。
